Commands

One command, a few flags. Run it inside any Git repo with a GitHub origin.

shipit

The standup. Drafts done items from your commits, listens (dictate with Wispr Flow, empty line to finish), shows the live board, asks yes / edit / no, then ships to GitHub and prints the receipt.

shipit

--text TEXT

Say it as an argument instead of dictating. Handy in scripts and demos.

shipit --text "Kal maine login fix kiya. Milap takes the balance bug by Friday."

--from-notes FILE

Feed a meeting transcript. One meeting becomes issues for everyone mentioned.

shipit --from-notes sync-notes.txt

--dry-run

Everything runs except the GitHub writes, which are printed as gh commands. Reads still happen, so duplicate checks are real. State isn't saved.

shipit --dry-run

--agent N

After shipping, Claude Code (claude -p) works your top N next issues in parallel, each in its own git worktree on shipit/issue-<n>. Shipit runs the tests, pushes, and opens a PR that closes the issue and quotes what you said. A failed agent keeps its branch.

shipit --agent 2

--debug

Ramble about a bug. Each hypothesis becomes a card with its own investigating agent, which reports confirmed or ruled out with evidence. Say “fix it” for a PR with a regression test.

shipit --debug --text "Chart shows negative saved time. Maybe the parser reads ? as zero..."

--review PR

Speak a review of a pull request. It's written up and posted, an agent addresses it on the PR branch and pushes, and saying “merge” squash-merges it.

shipit --review 7

--replay

Plays three recorded standups (English, Hinglish, meeting notes) through the board. No keys, no network: the demo that never dies on camera.

shipit --replay

--no-board

Terminal only; don't start the board or open a browser.

shipit --no-board

--port PORT

Where the live board listens (default 7878; Shipit picks a free one if that's taken).

shipit --port 9000

--version

Print the version and exit.

shipit --version

-h, --help

List the flags.

shipit --help

Environment

GROQ_API_KEY (required for parsing; put it in your repo's gitignored .env), GROQ_MODEL (default openai/gpt-oss-120b), SHIPIT_TEST_CMD (how agents' work is tested; auto-detected otherwise).
